# csi-rs/.github

Organization-wide configuration for [csi-rs](https://github.com/csi-rs).

| Path | Purpose |
|---|---|
| [`profile/README.md`](profile/README.md) | The public profile shown on the [organization page](https://github.com/csi-rs). |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Default Code of Conduct, applied to every csi-rs repository that does not ship its own. |
| [`CODEOWNERS`](CODEOWNERS) | Review ownership for this repository. |
| [`brand/`](brand/) | Brand assets and usage rules; the canonical source for every csi-rs logo URL. |

> **Note:** GitHub inherits community health files (such as the Code of
> Conduct) from this repository, but **not** `CODEOWNERS`. Each repository
> that needs code owners must define its own `CODEOWNERS` file.
